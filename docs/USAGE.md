# 使い方

Group Builder は、メンバーの属性をもとにグループ分けを支援するブラウザアプリです。

## 基本の流れ

1. メンバーを読み込む
2. 必要なら属性の型を確認する
3. Balance を調整する
4. General でグループ数や表示設定を決める
5. `GROUP BUILD` を実行する
6. 必要に応じてドラッグで手動調整する
7. CSV出力、印刷、Save As で保存する

## メンバー入力

CSV / Excel を読み込めます。

### 行の意味

- 1行目: 項目名
- 2行目: 型
- 3行目以降: メンバー

### 型

- `id`: メンバー名など。最適化対象外
- `category`: 性別、部署、学問分野など
- `numeric`: 年齢、経験年数、点数など
- `ordinal`: 1〜5の段階評価など
- `boolean`: はい / いいえ
- `ignore`: 備考など、最適化しない情報

## Template ボタン

Template を押すと、簡易サンプルがその場で読み込まれます。

項目:

- 名前
- 性別
- 年代
- 経験年数

## グループ作成

`GROUP BUILD` を押すと、現在の設定をもとに自動最適化します。

固定したメンバーは移動しません。

## 手動調整

カードはドラッグして別のスロットへ移動できます。

固定ボタンを使うと、そのメンバーは次回の自動最適化でも位置を維持します。

## Search

Search member に名前を入力すると、該当するカードが強調表示されます。

## Export

- `Export CSV`: 現在のグループ割り当てをCSV出力
- `Print View`: 操作用UIを減らして印刷
- `Save As`: プロジェクト保存
- `Open Project`: 保存済みプロジェクトを復元
